# ManeFunction Bucket

## How do I install these apps?

`scoop install manefunction/<app>`

Or add this bucket to Scoop: `scoop bucket add manefunction https://github.com/ManeFunction/scoop-bucket`,
then: `scoop install <app>`, once the bucket is added.

## Available Apps

- [lazyunity](https://github.com/ManeFunction/lazyunity) - A CLI for Unity projects and Editors, built on top of the official Unity CLI and inspired by lazygit.

## Documentation

`scoop help` or check [Scoop's documentation](https://github.com/ScoopInstaller/Scoop/wiki).
